# 251224_SnowflakeFractals

SnowflakeFractals explores generating snowflake-like fractal patterns, with goals of interactive rendering, parameter tweaking, and exportable imagery for generative art experiments.

## Features
- Recursive snowflake generator with tunable depth, symmetry, and randomness (planned)
- Real-time preview with pan/zoom and animation toggles (planned)
- Parameter presets and randomization seeds for reproducible outputs (planned)
- Export options for high-res images or vector snapshots (planned)

## Getting Started
- Clone: `git clone https://github.com/ekimroyrp/251224_SnowflakeFractals.git`
- Open the repository in your editor; implementation code will live here as components and scripts are added.
- As the renderer lands, follow module-specific setup notes (e.g., install Python/JS deps) that will be documented here.

## Controls
Planned interactive viewer controls:
- Zoom: scroll wheel or trackpad pinch
- Pan: click and drag
- Depth: increase/decrease recursion via +/- keys or UI slider
- Symmetry: cycle through symmetry counts with number keys or dropdown
- Animation: toggle auto-rotation or time-based perturbations with spacebar
